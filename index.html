开发者文档 · 通用物理引擎 PhysicsEngine

MotionLab 的物理层是一个与项目无关的通用核心 PhysicsEngine（基于 Matter.js）：只吃纯数据描述符，不依赖 DOM、渲染或任何文件格式。你可以把它单独下载到自己的项目里，用同一套 API 搭建物理模拟。核心文件只有两个：physics-engine.js（引擎本体，ES 模块）和 matter.min.js（Matter.js 0.19 本体）。

当前版本：MotionLab — · PhysicsEngine — · Matter.js —。引擎版本在代码里可读 PhysicsEngine.VERSION（模块同时导出 VERSION 常量）；设置面板的「关于」一栏显示的也是同一组版本号。

一、如何下载

  • 整站源码：打开仓库 github.com/xieyuke2026-cpu/Physics-engine，点 Code → Download ZIP；或用 git：git clone https://github.com/xieyuke2026-cpu/Physics-engine.git
  • 只要引擎（两个文件）：physics-engine.js · matter.min.js（打开后另存即可）

二、如何调用（最小示例）

Matter 必须先以普通 script 加载为全局变量；引擎是 ES 模块，用 type="module" 引入。也可以不挂全局，改用 PhysicsEngine.setMatter(Matter) 或构造参数 { matter } 注入。

<script src="matter.min.js"></script>
<script type="module">
  import { PhysicsEngine } from './physics-engine.js';

  const pe = new PhysicsEngine({ enableSleeping: true, substeps: 2 });
  // 静态地面
  pe.addBody({ kind: 'rect', x: 400, y: 560, width: 800, height: 40, isStatic: true });
  // 一个会弹跳的球
  pe.addBody({ kind: 'circle', x: 400, y: 120, radius: 18, restitution: 0.6 });

  let last = performance.now();
  function frame(now) {
    pe.advance(now - last);   // 固定时间步推进
    last = now;
    // 在这里读取 pe.allBodies() 里每个 body 的 position / angle 自行绘制
    requestAnimationFrame(frame);
  }
  requestAnimationFrame(frame);
</script>

三、常用 API 速览

  • 构造：new PhysicsEngine({ gravity: { x: 0, y: 1 }, enableSleeping, fixedDt, maxSteps, substeps })，setGravity(x, y, enabled) 改重力
  • 物体：addBody(desc) / removeBody(id) / clear() / allBodies() / count。desc 字段：kind（'circle' | 'rect' | 'polygon'）、x, y、radius（圆与多边形）、width, height（矩形）、sides（多边形边数）、density, friction, frictionAir, restitution, isStatic, lockRotation, vx, vy, angle（弧度）、userData（宿主自定义数据，原样透传）
  • 约束（弹簧 / 连杆）：addConstraint({ bodyA, bodyB, pointA, pointB, stiffness, damping, length })。bodyA 传 null 表示固定在世界坐标 pointA；stiffness 接近 1 即为硬连杆；removeConstraint(id) 删除，删物体会自动清理它的约束
  • 推进：advance(elapsedMs, speed) 固定步长累加器（任意刷新率都稳定）；stepOnce() 单步；setSubsteps(1–8) 子步防穿模（拖拽除外）
  • 存取：snapshot() 导出纯 JSON { bodies, constraints }；load(data) 还原
  • 交互：pick(x, y) 拾取；beginDrag(body, x, y) / moveDrag(x, y) / endDrag() 物理拖拽（可甩掷）；onCollision((a, b, pair) => …) 碰撞回调
  • 改属性：setVelocity / setPosition / setAngleDeg / setDensity / setFriction / setRestitution / setStatic / setLockRotation / stopMotion，都以单个 body 为单位，修改时会自动唤醒休眠物体

四、约定

  • 坐标单位为像素，y 轴向下；角度用弧度（setAngleDeg 除外，它收角度）。
  • 核心不做渲染：宿主每帧读取 body.position 与 body.angle 自行绘制；MotionLab 本身就是用这套核心搭的，它的 js/physics.js 只是场景格式适配层。
  • 同一核心还有一份独立打包（含说明与测试）在本机 ~/workspace/physics-engine/，与站内版本保持同步。
